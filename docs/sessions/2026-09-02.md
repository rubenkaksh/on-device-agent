## Decisions

- Treat native cancellation completion as the boundary before a subsequent
  prompt is allowed.
- On automatic stop-token detection, request native cancellation and drain the
  response lifecycle instead of breaking the stream immediately.
- Align the install metadata with the `.litertlm` URL. Existing installations
  made with `ModelFileType.task` must be reinstalled once to update metadata.
- Assistant message bubbles use long-press to copy; user bubbles are
  unaffected.
- `trimRight()` is applied at finalization, error, and stop paths — not during
  streaming — to preserve mid-stream fidelity.
- The `StopTokenFilter` in flutter_gemma is correct as designed; the infinite
  `<end_of_turn>` bug was a user-side routing error (`.litertlm` artifact
  registered as `ModelFileType.task`), not a package bug.
